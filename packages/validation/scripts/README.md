# Fixture generators

Phase 3 (ARCHITECTURE.md §17). These will be the Python scripts that compute
expected values against DoWhy, EconML, statsmodels, linearmodels, and dagitty
for each canonical problem in §10b, writing the results into `../fixtures/`.
They run out-of-band (not part of `npm run validate`, which only checks the
already-committed fixtures) and are kept here for provenance.

Not implemented yet — no Python environment is set up in this repo.
