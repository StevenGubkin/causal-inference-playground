# Project-specific instructions

## Before every push

Review `REMAINING.md` against whatever changed and update it if it's gone stale —
an item shipped, a new gap was discovered, priorities shifted. Update its "Last
reviewed" line (date + commit-ish of the change) even if no other edit is needed, so
staleness itself is visible. This runs alongside (not instead of) the existing
practice of aligning README.md/ARCHITECTURE.md/METHODS.md with the current
implementation state before a push.
